# AWS Cloud Journey

> A personal repository for AWS learning notes, structured revision, cloud concepts, and practical service understanding.

**Author:** Shagun Kimothi

## About This Repository

I created this repository to organize my AWS and cloud learning in one place. It contains course notes, revision material, service explanations, architecture concepts, diagrams, examples, and practical learning references.

This is primarily an AWS learning and revision repository. The notes are organized around the courses and topics I am currently studying, and they will evolve as I continue learning.

## AWS Learning Roadmap

The current learning path follows the material already present in the repository:

1. **Cloud foundations** — cloud computing, AWS global infrastructure, Regions, Availability Zones, and shared responsibility.
2. **AWS fundamentals** — AWS account access, the AWS Management Console, AWS CLI, IAM, MFA, and root-user best practices.
3. **Compute** — servers, Amazon EC2, AMIs, instance types, scaling, pricing, containers, and serverless compute.
4. **Networking** — Amazon VPC, network foundations, hybrid connectivity, edge networking, application networking, and networking security.
5. **Serverless applications** — AWS Lambda, event-driven architecture, invocation models, permissions, execution environments, lifecycle, error handling, and monitoring.
6. **Containers and managed application platforms** — Amazon ECS, AWS Fargate, and AWS Elastic Beanstalk.
7. **Infrastructure and delivery concepts** — AWS CloudFormation, infrastructure as code, deployment workflows, monitoring, logging, and CI/CD references found in the notes.

## Topics Covered

### AWS Fundamentals

- Cloud computing and deployment models
- AWS Regions, Availability Zones, and Edge Locations
- AWS shared responsibility model
- AWS Management Console and AWS CLI
- IAM, IAM roles, MFA, and least privilege

### Compute and Serverless

- Servers and client-server concepts
- Amazon EC2, AMIs, instance types, scaling, and pricing
- Containers and serverless compute
- AWS Lambda and event-driven architecture

### Networking

- Amazon VPC and network foundations
- AWS Transit Gateway and AWS PrivateLink
- AWS Direct Connect and Site-to-Site VPN
- Amazon CloudFront and edge networking
- Application networking and networking security

### Containers and Application Platforms

- Amazon ECS concepts: tasks, services, clusters, and capacity providers
- AWS Fargate
- AWS Elastic Beanstalk deployment and managed environments

### Infrastructure and Operations

- AWS CloudFormation and infrastructure as code
- Deployment workflows and AWS CodePipeline references
- Amazon CloudWatch monitoring and logging
- Application health and operational concepts
